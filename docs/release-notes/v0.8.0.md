# v0.8.0

## Overview

v0.8.0 establishes the baseline Aetheric Forge GitOps Bootstrap platform.

This release provides a functional GitOps-managed Kubernetes control plane including DNS, PKI, ingress, load balancing, and administrative access services. The platform now supports deterministic cluster bootstrap and ongoing GitOps-driven operations.

## Highlights

### GitOps Control Plane

- Argo CD deployment and reconciliation
- Declarative platform management
- GitOps-first operational model

### Networking

- MetalLB load balancing
- Ingress controller support
- Internal and external service exposure

### DNS

- BIND DNS services
- ExternalDNS integration
- Automated DNS management

### PKI

- step-ca certificate authority
- cert-manager integration
- Internal ACME services

### Administrative Access

- WireGuard management access
- Reduced reliance on publicly exposed administration endpoints

## Documentation

- README improvements
- Platform Component Catalog
- Architecture and operational documentation updates
