# v0.6 Release Notes

## Summary

Version 0.6 finalizes the OSS repository transition and aligns operational
bootstrap workflows with the `aetheric-forge/infrastructure` source of truth.

## Highlights

- Documentation branding updated from Black Circuit to Aetheric Forge
  for active runbooks and bootstrap guides.
- Active version references updated from `v0.5` to `v0.6`
  outside historical release notes.
- Pulumi default Argo repository URL updated to:

      git@github.com:aetheric-forge/infrastructure.git

- GitHub bootstrap runbook updated to use `v0.6` branch guidance and
  infrastructure repository URL.
- step-ca deployment metadata updated to Aetheric Forge naming.

## Notes

- Historical release notes (v0.4.x and v0.5) remain historical records.
- Internal DNS default domains remain unchanged in this release.
