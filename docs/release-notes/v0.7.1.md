# v0.7.1 Release Notes

## Summary

Version 0.7.1 consolidates a broad round of operational fixes across DNS, ingress, GitOps, bootstrap, and validation tooling for the v0.7 branch.

## Highlights

- Pulumi and bootstrap automation were refactored for cleaner structure and improved AWS-focused provisioning workflows.
- Internal DNS support was expanded and stabilized with BIND-based in-cluster DNS updates, external-dns integration, and related ingress/DNS fixes.
- Networking and ingress behavior was adjusted across ArgoCD, metallb, SSL redirect, and load balancer handling to reduce environment drift and improve dev routing.
- step-ca and cert-manager bootstrap paths were tightened, including startup and kustomize path fixes.
- GitOps autodeploy and root app finalizer handling were improved to reduce reconciliation drift.
- Kustomize validation and helper scripts were updated, and the CI workflow that depended on SOPS access was removed.

## Notes

- This release includes many environment and automation fixes across scripts, manifests, and generated values.
- No special migration steps are called out beyond reconciling updated manifests and scripts in the target environment.
